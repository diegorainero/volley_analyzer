EXECUTIVE SUMMARY
================================================================================

A new "Match Salvati" (Saved Matches) section has been added to the
MatchManagementWidget in the Volleyball Scout application. This feature
allows users to:

  • View all previously created matches in a list
  • Visually distinguish active (yellow ⏳) from completed (green ✅) matches
  • Resume incomplete scouts by clicking on a match
  • View details of completed matches
  • Automatically refresh the list when creating new matches

The implementation uses PyQt6 QListWidget with color-coded status indicators,
SQLAlchemy database queries, and Qt signal-slot pattern for clean architecture.

KEY FEATURES
================================================================================

1. MATCH LIST DISPLAY
   - Shows all matches from database ordered by date (newest first)
   - Format: [ICON] Home_Team vs Away_Team - DD/MM/YYYY HH:MM
   - Example: ⏳ Pallavolo Milano vs Atas Trentino - 28/01/2025 19:30

2. STATUS INDICATORS
   Active Matches (draft/in_progress):
     • Icon: ⏳ (hourglass)
     • Background: #FFF3CD (light yellow)
     • Text: #856404 (dark brown)

   Completed Matches:
     • Icon: ✅ (checkmark)
     • Background: #D4EDDA (light green)
     • Text: #155724 (dark green)

3. INTERACTIVE FUNCTIONALITY
   Click active match → Dialog: "Vuoi continuare lo scouting?"
     • Click Yes: Emit resume_match signal → Load formation panel
     • Click No: Close dialog, stay in Match Management

   Click completed match → Dialog: Match information (read-only)
     • Shows match details
     • Click OK to close

4. AUTO-REFRESH MECHANISMS
   • List refreshes after creating new match
   • List refreshes when navigating to Match Management view
   • Manual refresh via refresh_matches() method

================================================================================
TECHNICAL ARCHITECTURE
================================================================================

PATTERN: Signal-Slot (Qt Model)
FRAMEWORK: PyQt6
DATABASE: SQLAlchemy ORM (SQLite/PostgreSQL compatible)

SIGNAL FLOW:
  User clicks match in list
    ↓
  _on_match_clicked() called
    ↓
  Query database for match details
    ↓
  If active: Show resume dialog
     Yes → resume_match.emit(match_id)
           → main_window receives signal
           → show_formation_panel(match_id) called

  If completed: Show info dialog

DATABASE QUERY:
  SELECT * FROM matches
  ORDER BY date DESC

MATCH DATA STRUCTURE:
  Match {
    id: int (primary key)
    home_team_id: int (foreign key)
    away_team_id: int (foreign key)
    date: datetime
    status: string ("draft" | "in_progress" | "completed")
    competition: string
    venue: string
    notes: text (optional)
  }
