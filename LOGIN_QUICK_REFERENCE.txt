🔄 FLUSSO APPLICAZIONE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   APP LAUNCH
      ↓
   Init Database
      ↓
   Setup UI Sections (Dashboard, Teams, Formation, etc.)
      ↓
   Create Menu Bar (con Logout option)
      ↓
   AUTO-LOGIN (admin/password)
      ↓
   ┌─ Valid?
   │  ├─ YES → is_authenticated=True → Dashboard ✅
   │  └─ NO  → LoginDialog ← Manual input
   │
   └─ LoginDialog Loop
      ├─ User enters credentials
      ├─ Valid? YES → Dashboard ✅
      └─ Valid? NO  → Error message + Loop

🛠️ TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   Q: App non avvia?
   A: Controllare che PyQt6 sia installato
      pip install PyQt6

   Q: Database error?
   A: Controllare database.py e configurazione
      python volley_analizer/check_database.py

   Q: LoginDialog non appare?
   A: Auto-login è riuscito (normale!), prova Ctrl+L per logout

   Q: Enter key non funziona?
   A: Focus deve essere nel campo password
      self.password_input.returnPressed.connect(self.accept)
